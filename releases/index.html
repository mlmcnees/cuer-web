Release Notes

Version 1.2.18.0 November 2026

DanceMaster import

  • Before you start, the Import page now lists every folder your DanceMaster setup uses (playlists, cue cards, music and full cues) and marks any that aren’t on this computer.
  • If a folder is missing, Cuer explains what won’t come across (for example music, cue cards and karaoke timings) and waits until you either choose the right folders or tick “Import anyway without these files”.
  • A missing playlist folder no longer stops the import partway through.
  • After importing, Cuer uses every folder it found, even if some were missing. Previously one missing folder meant none of them were applied, so music and cue cards didn’t load.
  • If an import fails, Cuer says so and tells you where your previous library was backed up.

Other

  • Problem reports are more complete: Cuer no longer stops recording its session log after an unexpected error.

Version 1.2.17.0 November 2026

More room for cues on laptops

  • The Playback page and the Edit Dance Times tab give the cue card much more height on 1920×1080 screens.
  • The player and cue card toolbars hide their labels when space is tight. Hover over a button to see its name.
  • The Playback list can be narrowed or widened with the arrow on its divider, and Cuer remembers your choice. When the list is narrow and filters are on, a marker beside the search box shows that some dances are hidden.
  • The Playlist picker now sits beside the Playlist / All Dances switch.
  • The navigation pane remembers whether you left it open or collapsed.

Focus mode

  • Click the expand button at the end of the progress bar, or press F11, to hide everything but the player controls and the cue card while you cue. Press Esc to return.

Fixes

  • Editing or deleting a cue card file while its dance was loaded could crash Cuer.
  • Fixed a crash when leaving the player while in focus mode.
  • The Playlist Builder’s search box now says “Search playlists”.

Help

  • The Playback, Edit Dance Detail and Times tours have new screenshots for the new layout.

Version 1.2.16.0 October 2026

Imported from DanceMaster before this version? Please import again so every dance plays at the right speed. Re-importing replaces your Cuer database (the old one is backed up), so changes you made in Cuer since your first import will need redoing.

DanceMaster import

  • Fixed a crash partway through importing a DanceMaster library.
  • Dances now import DanceMaster’s playback speed adjustment. Previously the speed was calculated from the turntable speed field: when that field was blank the dance loaded but never played, and other dances played at the wrong speed (33 RPM records about 27% slow).
  • Updating automatically fixes dances that wouldn’t play.

Music and cue cards

  • Music and cue card files are matched regardless of upper/lower case.
  • .wav, .wma and .m4a music files are now recognized, as well as .mp3.
  • When a dance’s music or cue card file can’t be found, Cuer records it in the session log, which makes problem reports easier to diagnose.

Editing dances

  • Opening a dance in the editor and closing it without changing anything no longer asks whether to save.

Help

  • The numbered markers in every page tour now line up with what they describe, and the pictures are larger.
  • The Edit Dance Detail and Times tours have real screenshots, and the tour text matches the current pages.

Other

  • The About page and title bar show the actual installed version.
  • Improved stability: background tasks no longer crash the app when the database is briefly busy.

First Microsoft Store release 2026

Cuer is now available on the Microsoft Store. Release notes for individual versions will be posted here going forward.
